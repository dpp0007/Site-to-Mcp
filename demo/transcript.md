# Demo: multi-step use of several tools over the real MCP protocol

Generated by `python demo/run_demo.py 2026-11-14` - every response below is the server's actual output (live TinyFish calls), including the deliberate error cases.

## Tools the client sees
- `mit_list_departments`: List all MIT departments/programs with their course-number prefix (e.g. '6' = EECS). Start here to find a prefix.
- `mit_list_department_courses`: List subjects in one MIT department by course-number prefix (e.g. '6', '18', '21M').
- `mit_search_courses`: Keyword search across all MIT subjects (title + description; every word must match; best title matches first). Optionally restrict to one department prefix. Empty list = genuinely no match.
- `mit_get_course`: Full detail for one MIT subject number (e.g. '6.1210'): description, prerequisites (+ parsed prerequisite codes), instructors, terms offered. NOT_FOUND if the subject does not exist.
- `get_park_conditions`: Current alerts and road/area closures for a US National Park, by 4-letter park code (yose, grca, yell, zion, romo...). NOT_FOUND for an unknown code.
- `list_nyc_parks_event_categories`: Valid category slugs for list_nyc_parks_events (kids, fitness, birding, concerts, ...). Call this first if unsure which category to pass.
- `list_nyc_parks_events`: NYC Parks events on one date (YYYY-MM-DD), optionally filtered by category slug and/or borough (Manhattan, Brooklyn, Queens, Bronx, Staten Island). 50 per page; use `page` for more. Each event has a url for get_nyc_parks_event.
- `get_nyc_parks_event`: Full detail for one NYC Parks event from its url (as returned by list_nyc_parks_events): address, cost, organizer, contact. NOT_FOUND if the page does not exist.
- `list_python_events`: Upcoming Python community conferences and meetups worldwide (name, ISO start/end dates, location), soonest first.
